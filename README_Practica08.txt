Archivos para la Práctica 08: Representación gráfica de datos y cálculo de medidas de tendencia central y dispersión

Contenido:
1. COVID19MEXICO.csv
   - Conjunto de datos sintético con 1,200 registros tipo COVID-19 en México.
   - Fue construido únicamente con fines didácticos para practicar estadística descriptiva en Python.
   - No debe usarse como fuente epidemiológica oficial.

2. PLCOVID19.ipynb
   - Notebook de Jupyter con instrucciones, código comentado y preguntas de interpretación.
   - Incluye carga y limpieza de datos, medidas de tendencia central, medidas de dispersión, tabla de frecuencias para datos agrupados y no agrupados, histogramas, dispersión, caja y bigotes, tallo y hojas, Pareto y gráfico circular.

Requisitos sugeridos:
- Python 3.10 o superior
- Jupyter Notebook o JupyterLab
- pandas
- numpy
- matplotlib

Instalación rápida:
pip install pandas numpy matplotlib notebook

Ejecución:
1. Coloque COVID19MEXICO.csv y PLCOVID19.ipynb en la misma carpeta.
2. Abra una terminal en esa carpeta.
3. Ejecute: jupyter notebook
4. Abra PLCOVID19.ipynb y ejecute las celdas en orden.
